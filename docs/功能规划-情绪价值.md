# 情绪化功能规划 · v1.1 → v1.3

> 目标：把「一块很好看但很安静的工时牌」变成「一天里会给你几个小瞬间的桌面伙伴」。
> 前提：不加负担、不改工具属性、不为情绪牺牲可读性。

---

## 一、先给结论

现状是**美术 9 分、情绪 5 分**。它把「还有多久下班」这件事做到了极致，但**一天里只服务了一个情绪时刻**——临近下班的期待。而上班族真正难熬的是四个时刻：

| 时间 | 真实心理 | 现在被服务了吗 |
|---|---|---|
| 09:00 刚坐下 | 抗拒、拖延、不想开始 | ❌ 只有倒计时默默启动 |
| 12:00 午休 | 松一口气 | 🟡 有「休息中」，但画面是静止的 |
| 15:00–16:00 低谷 | 疲惫、走神、怀疑人生 | ❌ 完全空白，且倒计时数字放大焦虑 |
| 17:40 临近下班 | 躁动、期待 | ✅ 倒计时最擅长这里 |
| 18:00 之后 | 沮丧、被剥夺感 | 🟡 只有「已加班 XX 分钟」，越看越丧 |

**核心问题不是缺功能，是缺"事件"。** 现在的界面是一条连续的渐变（草在长、天在变色），没有一个是"发生"的。人记得住的从来不是渐变，是事件。

所以三批功能的逻辑是：

1. **v1.1 造峰值**——把「开工 / 达成 / 下班」做成看得见的事件（成本最低，情绪收益最高）。
2. **v1.2 造陪伴**——让草地上有活物、有天气，一天的空白时段有人陪。
3. **v1.3 造长期**——把「加班账本」换成「这块地的收成」，让时间有累积感而不是被剥夺感。

---

## 二、现有功能 × 场景契合度盘点

| 功能 | 它实际解决的问题 | 情绪作用 | 契合度 | 短板 |
|---|---|---|---|---|
| 无边框置顶 + 右键穿透 | 不挡工作、不抢焦点 | 无感（这是及格线） | ★★★★★ | 无 |
| 倒计时数字 | 精确知道还剩多久 | 单向：只放大焦虑，不给安慰 | ★★★★ | 越接近下班越躁，越超时越丧 |
| 草地生长条 | 把"熬时间"变成"看草长" | 掌控感、进度感 | ★★★★★ | 纯渐变，没有可记忆的瞬间 |
| 天空 / 云 / 天色 | 让静止的界面"活着" | 氛围、时间流逝感 | ★★★★ | 几小时才被注意到一次 |
| 花海 + 每天三种主花 | 每天不一样 | 新鲜感 | ★★★★ | 变化太静，用户不知道"今天不一样" |
| 每日一句（481 句） | 一天一个情绪触点 | 被理解、被点醒 | ★★★★ | 一天只有一次，读完即止 |
| 草皮卷 | 把前沿拟物化 | 细节彩蛋 | ★★★ | 太细，多数人不会注意到 |
| 累计加班 / 最近记录 | 记账 | **负向**：数字越大越沮丧 | ★★ | 只有加班，没有"正常下班"的正向表达 |
| 三档尺寸 / 托盘 / 自启 | 工具性适配 | 无感 | ★★★★ | 无 |

**盘出来的三个空洞：**

- **空洞 A：没有峰值。** 全天的情绪是一条平线，没有任何"哇"的一秒。
- **空洞 B：没有活物。** 风景很美，但没有人、没有动物、没有回应——它是海报，不是伙伴。
- **空洞 C：没有正向叙事。** 唯一的长期数据是加班时长。也就是说，这个产品**只在你不幸的时候记录你**。

## 三、设计原则（写代码前先立规矩）

1. **一秒可读**：所有新元素必须在"余光扫一眼"里成立，不做需要阅读的文本流。
2. **不抢注意力**：单次动效 ≤ 3 秒，一天 ≤ 5 次；默认零声音；全部可关。
3. **环境叙事优先于文案**：能用天色/花/生物表达的就不写字，文字只用来点题。
4. **每天不同，但不能失真**：一律按 `day.toordinal()` 播种（沿用现有 `seed_day`），同一天刷新画面完全固定。
5. **不做第二件事**：它只管"时间"，不做待办、不做番茄钟、不做喝水提醒。

## 四、功能清单（按优先级）

### P0 · v1.1 峰值时刻（改动面小，情绪收益最高）

#### F1 下班那一刻：草卷滚出画面 + 木牌升起
- **核心作用**：达成 9 小时整的一瞬间，草皮卷从右侧滚出画面，天空放一小簇像素烟花，一块木牌从下方升起来写「下班」。
- **目标情绪**：**释放感 / 完成感**。把"熬完"变成"干完了"。这是全天唯一允许"夸张一点"的 2.6 秒。
- **实现思路**：
  - `widget._tick()` 里记 `self._prev_state`，检测 `WORKING → OVERTIME`（或 `progress` 首次到 1.0）的跨越，置 `self._fx = ("done", t0)`。
  - 复用现成的 40ms 临时定时器机制（`_anim_step` / `_animating`），只在这 2.6 秒提到 25fps，结束自动回落 1fps。
  - `theme.draw_done_fx(p, ...)`：木牌用现成的 `texture("wood")` + `draw_cjk_vcenter`，烟花是 3 帧 8×8 像素爆点（白→黄→橙→暗红，逐帧掉格）。
  - 触发一次后当天不再触发（`store` 记 `celebrated:<date>`）。
- **风险/开关**：`ui.fx.celebrate`，默认开；怕吵的人可关（关掉就只是数字变化）。

#### F2 里程碑：花瓣爆开
- **核心作用**：进度跨过 25% / 50% / 75% / 90% 时，前沿那卷草皮旁边爆开一小簇花瓣（6–10 个像素点，飞 12 帧落地消失），同时脚下的百分比重描一次。
- **目标情绪**：**阶段感 / 被奖励**。4 小时、6 小时这种"看不见的墙"变成 4 个可以数的小胜利。
- **实现思路**：`_tick()` 里把 `progress` 和上次记录比，跨阈值就 `theme.draw_petal_burst(p, x, gy, seed)`；粒子颜色取当天主花（已有主花逻辑）；去重存 `self._hit = {0.25, 0.5, ...}`，跨重启用 store 的当日字段。
- **风险/开关**：`ui.fx.milestone`，默认开。粒子必须**小**——1 单位 = 2px，超过 8 个就成噪点。

#### F3 时段问候：header 换成会说话的一句
- **核心作用**：顶部「工作计时」四个字按状态和时段变：早上「开工了」、午后低谷「最难的一段」、17:30 后「快熬到头」、超时「该回家了」、周末「今天不用上班」。
- **目标情绪**：**被理解**。这是最便宜的情绪设计——同一个位置，一句话就让人觉得"它知道我现在什么感受"。
- **实现思路**：
  - `quotes.py` 加 `greeting(state, now, progress) -> str`，按时段表分桶，每桶 6–8 个变体，`day.toordinal() % len()` 取（和每日一句同一套确定性手法）。
  - 渲染位置复用 `L["title"]`，小档也有这个位置（正好填住 `title_x` 之后的空当）。
  - **硬约束**：≤ 6 个汉字，字号 11 单位，超了会被进度条挤掉。
- **风险/开关**：`ui.fx.greeting`。文案必须"短且不油"，宁可朴素。

#### F4 加班入夜：萤火虫 + 卷子变慢
- **核心作用**：进入 `ST_OVERTIME` 后，天色继续往深夜走（在 `_visual_hour` 上叠一个 0.8 小时的偏移），草地上浮出 3–5 个忽明忽暗的萤火虫，草皮卷的待机转速降到 40%。
- **目标情绪**：**体谅 / 一点温柔的催促**。不用文字说"早点回家"，让环境替你天黑。
- **实现思路**：`_visual_hour()` 加 OT 偏移；`theme.draw_fireflies(p, ..., secs, seed_day)`，每个萤火虫是单格 2×2 像素，亮度按 `sin(secs * k + phase)` 在两级之间跳（不做渐变，保持像素感）；`sod_roll_idle_speed` 读时乘系数。
- **风险/开关**：`ui.fx.firefly`。

#### F5 午休小剧场：云遮日 + 花合上 + Zzz
- **核心作用**：12:00–13:00 时，太阳挪到正中偏右，一朵云慢慢飘到太阳前面，花冠收拢一格，画面右下浮起三个上下跳的「z」。
- **目标情绪**：**松弛 / 被允许休息**。让"午休"从一行文字变成一段可以看的画面。
- **实现思路**：`state == ST_LUNCH` 时走 `theme.draw_lunch_fx`；花高在 `_draw_flower_field` 里乘 0.75 并跳过花冠；Zzz 用 `draw_cjk_vcenter` 画 3 个字母，透明度按秒呼吸（两档跳变）。
- **风险/开关**：`ui.fx.lunch`。

### P1 · v1.2 陪伴（需要少量新数据）

#### F6 路过的小生物
- **核心作用**：一天里 2–3 次，一只像素蜜蜂 / 鸡 / 猫从草地一端走到另一端（约 12 秒），不交互、不打断。
- **目标情绪**：**惊喜 / 陪伴**。这是投入产出比最高的一项：几帧动画，换一整天的"今天它会不会来"。
- **实现思路**：`day.toordinal()` 播种出 2–3 个出现时刻（如 10:20、15:40），`_content()` 里判断 `now` 落在窗口内就传 `critter=(kind, x_unit, frame)` 给 `draw_meadow_bar`；走到头就消失，过了时段不补。
- **风险/开关**：`ui.fx.critter`（0 = 关，1–3 = 每天几只）。**必须稀**，一天十次就变成干扰。

#### F7 天气系统
- **核心作用**：按日期播种晴（60%）/ 多云（20%）/ 小雨（12%）/ 薄雾（8%）；雨天有 2 帧雨丝、草地加湿、卷子拖泥；雾天在地平线压一条半透明灰带。
- **目标情绪**：**真实感 / 共情**。"今天下雨"和窗外的天气对上时，那种"它跟我活在同一个世界"的感觉非常强。
- **实现思路**：`weather_of(day)` 纯函数（哈希 `toordinal()` 取模，加权），不存状态；`_draw_sky` 里插滤镜，`palette_at` 里乘饱和度；雨丝在 `draw_meadow_bar` 最后画，1 单位宽、2 单位长，随机偏移但按秒只走 1 格。
- **风险/开关**：`ui.fx.weather`。不要做雷电/闪白，会吓人且费电。

#### F8 连击：连续准点下班 → 稀有金花
- **核心作用**：连续 N 天没加班，草地末尾长出一丛金色蒲公英；foot 显示「连续 7 天准点」。断一次清零，保留历史最长。
- **目标情绪**：**长期目标 / 自我肯定**。把"今天没加班"从无感变成"我在攒一条链"。
- **实现思路**：`store.settle()` 已有按天结算的钩子，加 `streak` / `best_streak`；花色池加一个 `golden` 变体，只在 `streak % 7 == 0` 时插到当天花种里。
- **风险/开关**：`ui.fx.streak`。**不要**做成断链就惩罚的文案，只在达成时说好话。

#### F9 今天这块地（当日小结）
- **核心作用**：右键菜单加一项，弹一个像素小面板：今天铺了几格草、开了几朵花（按当天花种算）、在座多久、有没有加班，末尾一句自嘲或夸奖。
- **目标情绪**：**被看见 / 收尾仪式**。一天结束有个"存档"动作，比看数字舒服。
- **实现思路**：数据全部现成（`snap.worked_minutes`、`progress`、花种、`day_overtime`）；文案用模板 + 数据填充，不接大模型；面板复用 `draw_panel` + 点阵字，尺寸控制在 3/4 窗口。
- **风险/开关**：菜单项常驻即可，不需要开关。

#### F10 一周五块田
- **核心作用**：右键里给一个"本周"视图：五块小田，每天一块，填满程度 = 当天工时，周末变"休耕"。
- **目标情绪**：**时间有形状**。一眼看见"这周我已经耕了四块地"。
- **实现思路**：`store.recent_days()` 已有；画 5 个 12×8 单位的小方块 + 缩略草皮。**不改主界面**——主界面是单日叙事，别破坏。
- **风险/开关**：改动面 M，放在 P1 末尾。

## 七、落地顺序建议

1. **先做 F1 + F3**（S 级，各半天的量）。这两项一上，产品性质就变了——从"计时器"变成"会说话的东西"，而且不新增任何数据。
2. **再做 F2 + F5 + F4**（S 级）。补满"事件"，P0 收口，可以发 v1.1。
3. **F6 小生物**先做（S 级），它是陪伴感的性价比之王；F7 天气（M 级）看 F6 的反应再决定。
4. **F8 / F9**（M 级）进入 v1.2，开始积累长期数据。
5. **F10 及 P2** 视 `interactions` 数据决定——如果一周里主动交互次数 < 1 次/天，说明该往"更安静"走，而不是加更多功能。

## 八、怎么判断做对了

- 一周内至少有 3 天，你会**主动**看它一眼（不是瞥时间，是等那个瞬间）。
- 出现"想关掉"的瞬间 = 失败：说明动效太长、太频繁或太亮。
- 把 `fx` 全部关掉后，界面与今天完全一致——说明特效是叠加的，不是嵌进主逻辑的。
- `interactions` 统计里，点击/菜单次数稳中有升，而不是装完两天后归零。

## 九、明确不做的事

| 不做 | 原因 |
|---|---|
| 番茄钟 / 待办清单 | 越界。它一旦能管理任务，就会变成"又一个要维护的工具"，快乐立刻变成负担 |
| 久坐提醒 / 喝水弹窗 | 打断式提醒在下班倒计时旁边只会加倍焦虑 |
| 社交 / 排行榜 / 同事工时对比 | 上班场景的攀比会反噬，且涉及隐私 |
| 复杂 3D、粒子光效、动图资源 | 破坏「1 单位 = 1 像素」的视觉语言，也会让 exe 变大、掉帧 |
| 大段文本（日志、感悟、AI 生成内容） | 一秒可读原则。每日一句的容量已经是上限 |
