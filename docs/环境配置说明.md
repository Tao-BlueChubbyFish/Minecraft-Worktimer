# 环境配置说明

## 一、运行环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 (1809+) / Windows 11，64 位 |
| Python | 3.10 ~ 3.13（64 位） |
| 依赖 | PySide6（唯一运行依赖） |
| 分辨率 | 按 2560×1440 调校，1080P / 4K 会自动缩放 |
| 网络 | 运行时不联网；仅首次装依赖需要 |

程序本身不需要管理员权限；「开机自启」只写当前用户的注册表 `HKCU`，也不用提权。

## 二、安装与启动

### 方式 A：一键启动（推荐）

双击 `启动.bat`：
1. 按 `py -3` → `PATH 里的 python` → 常见安装目录的顺序找一个**能真正运行**的 Python
   （会自动跳过微软商店那个假的 `WindowsApps\python.exe` 占位程序）；
2. 缺 PySide6 时自动 `pip install -r requirements.txt`，官方源失败会自动换清华镜像；
3. 用 `pythonw.exe` 启动，**不弹控制台黑框**，脚本窗口自己会关掉。

找不到 Python 时脚本会停住并提示两条路，不会一闪而过。

### 方式 B：手动

```bat
cd Python版
python -m pip install -r requirements.txt
pythonw main.py
```

国内网络慢就换源：

```bat
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 首次启动会在项目目录自动生成 `config.json` 与 `data.json`。项目里已经放了一份默认
> `config.json`，可以直接改。

## 四、config.json 参数总表

改完保存，**重启程序生效**。程序启动时会用默认值补齐缺失字段，写错类型也不会崩。

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `passthrough_seconds` | 数字 | `3` | 右键触发临时穿透后，多少秒自动恢复（0.5 ~ 30） |
| `font_scale` | 数字 | `1.0` | 界面与文字整体缩放（0.6 ~ 2.5） |
| `palette` | 字符串 | `"grass_stone"` | 配色方案：`grass_stone` / `stone_night` / `dirt_wood` |
| `palette_override` | 对象 | `{}` | 单独覆盖某个颜色，见下表 |
| `autostart` | 布尔 | `false` | 开机自启；`true` 时启动会写入注册表 Run 项 |
| `ui.always_on_top` | 布尔 | `true` | 是否保持置顶 |
| `ui.opacity` | 数字 | `1.0` | 正常状态整体不透明度 |
| `ui.passthrough_opacity` | 数字 | `0.45` | 穿透状态的不透明度 |
| `ui.right_click_action` | 字符串 | `"passthrough"` | 右键行为：`passthrough`（穿透）或 `menu`（直接弹菜单） |
| `ui.pixel_scale` | 整数 | `0` | 像素块大小；`0` = 按屏幕高度自动（1440P → 2，4K → 3） |
| `ui.size_tier` | 字符串 | `"standard"` | 窗口尺寸档：`small`（336×112 迷你）/ `standard`（432×242）/ `large`（648×363） |
| `ui.progress_style` | 字符串 | `"meadow"` | 进度条样式：`meadow`（草地生长）/ `plain`（纯色填充） |
| `ui.daylight_tint` | 布尔 | `true` | 草皮、泥土与**天空**连续变化（黎明粉紫 → 正午亮蓝 → 黄昏橙红 → 夜里深蓝带星），云也会飘；关掉则固定正午天色、云静止 |
| `ui.sky_mode` | 字符串 | `work` | `work` = 一整套天色压缩到你的上班时段里走完（开工天亮、下班前入夜，改了上班时间会跟着平移）；`clock` = 严格按真实钟点（凌晨的日出、深夜的星空也在真实时刻） |
| `ui.sky_span_hours` | 浮点 | `13.0` | 配合 `sky_mode=work`：从上班算起多少小时走完「日出 → 入夜」。8:00 上班、干到 21:00，就填 13；只干 9 小时填 9.5，天色会走得更快 |
| `ui.sod_roll` | 布尔 | `true` | `true` = 进度前沿是一卷草皮，随进度一路往右滚着把草地铺开（推进时卷按走过的距离转、会颠、会扬土）；`false` = 恢复成直边前沿 |
| `ui.sod_roll_idle` | 布尔 | `true` | 不推进的时候草皮卷也慢慢转，看起来是活的；关掉就完全静止（省一点点电） |
| `ui.sod_roll_idle_speed` | 浮点 | `0.012` | 待机转速：每秒转多少圈（0.012 ≈ 80 秒转一圈；调大了就像原地打转，不推荐超过 0.05）。0 = 不转 |
| `ui.quote` | 布尔 | `true` | `true` = 标准/大档在进度条下面显示一行每日一句；`false` = 整行不画（位置保留，窗口高度不变）。小档本来就没有这一行 |
| `ui.quote_shuffle` | 布尔 | `true` | `true` = 先按固定种子洗牌再按日期取，看不出顺序；`false` = 按列表原顺序一天一句地轮 |
| `ui.quotes` | 字符串数组 | `[]` | 自定义句子列表，留空用内置的 481 句（333 句通用 + 148 句米哈游台词：原神 45、星穹铁道 54、崩坏3 32、绝区零 17）。周期 = 列表长度，轮内不重复；单句建议不超过 15 个汉字（更长会自动降字号）。句末的「。」会被自动去掉 |
| `ui.fx.greeting` | 布尔 | `true` | 顶部「工作计时」按时段/状态换成一句问候（开工了 / 最难的一段 / 该回家了…）；`false` = 固定文案 |
| `ui.fx.milestone` | 布尔 | `true` | 跨过 25% / 75% / 90% 时卷子跳一下、百分比变金、短语顶 8 秒 |
| `ui.fx.celebrate` | 布尔 | `true` | 选「回家」时的 5 秒庆祝（六簇烟花 + 44 片彩纸）；`false` = 直接切到收工状态 |
| `ui.fx.offer` | 布尔 | `true` | 到点后弹「回家 / 再干会儿」。关掉后木牌仍在、仍可点，只是不会自动弹 |
| `ui.fx.offer_idle_seconds` | 整数 | `25` | 到点后多久没反应就自动弹出选项（5~600 秒） |
| `ui.fx.life` | 布尔 | `true` | 一天 2~3 次有一群鸟从天空飞过（时刻按日期算，今天几点来固定） |
| `ui.fx.moon` | 布尔 | `true` | 日落后天空挂一轮月亮，云从它前面飘过 |
| `ui.fx.props` | 布尔 | `true` | 草地上的道具（木栅栏 / 干草堆 / 石堆），铺到对应进度才出现 |
| `ui.fx.fps` | 整数 | `60` | 动效帧率（15~120）。卷的滚动、里程碑、烟花都走这条线；调低可省电 |
| `ui.corner_margin` | 整数 | `32` | 第一次启动时距屏幕右下角的边距 |
| `schedule.default_work_start` | 字符串 | `"09:00"` | 未登记时聊天窗提示的默认上班时间 |
| `schedule.offwork_time` | 字符串 | `""` | **下班时刻**（`"18:00"`）。留空 = 还没选过，按 `onsite_hours` 推算；在设置里选过一次之后就一直用它 |
| `schedule.onsite_hours` | 数字 | `9.0` | 在岗总时长（含午休）。现在只用于两件事：第一次启动推默认下班时间、下班时刻填错时兜底 |
| `schedule.lunch_start` | 字符串 | `"12:00"` | 午休开始（本地时间）。进度条上那面小旗就插在这个位置，里程碑也靠它避开午休 |
| `schedule.lunch_minutes` | 整数 | `60` | 午休时长（分钟，0~240）。**改这一项就够了**，结束时间由它推出来 |
| `schedule.lunch_end` | 字符串 | `"13:00"` | 午休结束。老配置兼容用：没有 `lunch_minutes` 时才会读它反推时长，平时留空也行 |
| `schedule.workdays` | 数组 | `[1,2,3,4,5]` | 工作日，1=周一 … 7=周日；改成 `[1,2,3,4,5,6]` 就是单休 |
| `schedule.ask_start_on_launch` | 布尔 | `true` | 当天没登记上班时间时，启动自动弹输入框 |

有效工时 = 上班→下班 的跨度 − 落在午休里的那一段。默认 9:00 上班、18:00 下班、午休 60 分钟，
就是 9 − 1 = **8 小时**。10:00 才上班，同一天的有效工时自动变成 7 小时（下班时间不动）。

`offwork_time` 为空时（第一次启动）按 `onsite_hours` 推：9:00 + (9 − 1) 小时，跨午休顺延，
得到 18:00，设置界面里会把这个值垫在输入框里等你改。下班时刻早于上班时刻时同样退回按
`onsite_hours` 推算，不会算出负数。

这四项（上班时间 / 下班时间 / 午休开始 / 午休时长）都可以在右键菜单「设置…」里改，
改完立刻生效并写回 `config.json`，重启不会丢。

### 配色覆盖

`palette_override` 里可以只写想改的键，例如把面板换成更暗的石头、进度条换成蓝紫色：

```json
"palette_override": {
  "panel": ["#4a4a4a", "#505050", "#444444", "#565656", "#3f3f3f"],
  "bevel_light": "#6a6a6a",
  "bevel_dark": "#222222",
  "text": "#f0f0f0",
  "text_dim": "#a8a8a8",
  "accent": "#5a7fb0",
  "fill": ["#5a7fb0", "#6b90c2", "#4a6d9c"],
  "fill_light": "#8fb3e0",
  "fill_dark": "#38537a"
}
```

可用键：`outline`、`panel`（数组，噪点色池）、`panel_shade`、`bevel_light`、`bevel_dark`、
`text`、`text_dim`、`text_on_grass`、`text_shadow`、`accent`、`grass`、`dirt`、`track`、
`fill`、`fill_light`、`fill_dark`、`warn`。数组表示随机取色，一般给 3~5 个相近色。

## 五、data.json 说明

```json
{
  "cumulative_overtime_minutes": 1250,   // 已结算的累计加班（不含今天）
  "ledger": {"2026-11-17": 45},          // 每天结算的加班分钟数
  "schedule": {"2026-11-18": "09:00"},   // 每天登记的上班时间
  "last_settled_date": "2026-11-17",
  "last_seen": "2026-11-17T20:45:03",
  "today_overtime": 0,
  "today_date": "2026-11-18",
  "window": {"x": 2088, "y": 1190},      // 上次窗口坐标
  "max_single_day": 180,
  "days_counted": 12
}
```

* **零点自动清空当日加班**：当天加班会被结算进 `cumulative_overtime_minutes`，当天面板归零；
  累计值不会随零点重置，只有菜单里的「清空累计加班」手动才会清零。
* 更新程序只需保留 `config.json` + `data.json` 两个文件，历史加班记录不会丢。
* 数据每 30 秒与退出时落盘，写文件用临时文件替换，断电不会写坏。

## 六、想用真·像素字体（可选，效果更好）

程序默认把中文按 12px 点阵渲染再整数倍放大（MC 中文就是这样显示的），数字用内置 5×7
点阵。如果你装了真正的像素字体，会自动优先使用：

1. 把 `.ttf` 丢进 `assets/fonts/`（打包时会被一起带上）；
2. 或直接把字体装到系统里。

推荐（均为免费可商用像素字体）：`Zpix 最像素`、`缝合像素字体 Fusion Pixel 12px`。
程序按以下顺序找：`Zpix` → `Fusion Pixel 12px` → `缝合像素字体` → `unifont` →
`SimSun` → `Microsoft YaHei`。

## 七、打包成独立 exe

见同级目录 `打包工程/一键打包exe.bat`，产物为单文件 `MCWorkTimer_v1.1.exe`，
目标机器无需 Python / PySide6。`console=False` 已配置好，不会出现控制台黑框。

> ⚠️ **两种启动方式的数据是分开的**：源代码版读写 `Python版\data.json`，
> exe 版读写 `exe启动版\data.json`。选定一种长期用，别两边混着开，
> 否则当天上班时间和加班台账会各记一份。

## 八、常见问题

**Q：右键没反应 / 菜单出不来？**
默认右键是「临时穿透」。想改回菜单：把 `ui.right_click_action` 改成 `"menu"`。
面板右上角的三横线按钮、托盘图标右键，随时都能打开完整菜单。

**Q：穿透状态点不到窗口，怎么恢复？**
不用管，到时间（默认 3 秒）会自己恢复。等待期间窗口半透明 + 绿色边框就是穿透中的提示。

**Q：双击没反应？**
看托盘有没有草方块图标 —— 可能已经最小化到托盘了。也可能是程序已在运行（单实例保护）。

**Q：位置跑到屏幕外了？**
删掉 `data.json` 里的 `"window"` 字段，重启会回到右下角。

**Q：时间算得跟我手算差一分钟？**
秒级向下取整，且午休整段不计入工时；跨午休的班次会自动顺延，属于正常。
