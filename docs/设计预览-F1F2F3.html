四、两处与原计划不同的地方

原计划里 F2 是「花瓣爆开」、F1 是「像素烟花」。实机渲染出来都读不出来， 所以换了表达方式——判断依据就是下面这张放大对照。

为什么换：进度条里几乎没有空地——花冠长到贴着上沿，任何 1 单位的粒子都会糊进花海； 面板灰底上小圆环又太淡，看着像脏点。结论是这个尺寸下只认"形状变化"和"颜色跳变"， 不认"粒子数量"。所以：
· F2 从"花瓣"改成 卷跳 + 百分比变金 + 短语；
· F1 从"圆环烟花"改成 十字星芒（5~9 个像素，形状本身自明）+ 木牌。

六、需要你拍板的 5 件事

  1. 木牌文案：现在是「收工」两字（比例最舒服）。备选「下班了」「今天到这」。
  2. 木牌位置：现在盖住大号数字那一行 2.6 秒。若不想遮数字，可改到进度条内（会挡草地）。
  3. 金色百分比：里程碑时右下角 50% 变金 1.2 秒。有人会觉得太抢眼，可只保留卷跳。
  4. 里程碑时刻：25 / 50 / 75 / 90% 四个，还是只留 50% 与 90%（少即是多）。
  5. 问候基调：现在是朴素的「开工了 / 走了一半 / 快熬到头 / 该回家了」。 要不要掺一点自嘲梗（例：「今天也要好好活着」），还是保持干净不抖机灵。
